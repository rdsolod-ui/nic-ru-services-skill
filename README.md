# NIC.RU Services

Устанавливаемый Agent Skill для работы с Руцентром в Codex и Claude Code. Версия 1.0.0.

Навык помогает найти нужную услугу и сверить договор, домен или IP. Он описывает работу с доменами, делегированием и DNS-записями, почтой, SSL, виртуальным хостингом и VPS. Ссылки на официальные источники находятся в справочниках внутри навыка.

## Установка

Скачайте `nic-ru-services-v1.0.0.zip` и распакуйте. Если скачиваете исходники через GitHub → Code → Download ZIP, откройте папку репозитория внутри архива. Скопируйте папку `nic-ru-services` целиком в один или оба каталога. При наличии предыдущей версии сначала сохраните её копию и замените папку целиком.

| Среда | Для пользователя | Для проекта |
| --- | --- | --- |
| Codex | `~/.agents/skills/` | `.agents/skills/` |
| Claude Code | `~/.claude/skills/` | `.claude/skills/` |

На Windows `~` соответствует папке пользователя. После установки конечный путь должен заканчиваться на `skills/nic-ru-services/SKILL.md`. Можно скопировать ту же папку из исходников репозитория. Зависимости не требуются.

Начните новый сеанс. В Codex укажите `$nic-ru-services`, в Claude Code вызовите `/nic-ru-services`. Например, попросите определить, где менять MX для домена, или проверить, относится ли панель хостинга к VPS с заданным IP. В Claude.ai ZIP можно загрузить как пользовательский навык, если эта функция доступна в аккаунте.

[Установка в Codex](https://developers.openai.com/codex/skills) · [Claude Code](https://code.claude.com/docs/en/skills) · [Claude.ai](https://support.claude.com/en/articles/12512180-use-skills-in-claude)

Навык содержит инструкции и справочники. Доступ к кабинету и право менять услуги зависят от авторизации в используемом клиенте.
